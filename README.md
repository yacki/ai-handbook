# 从预测下一个词到构建智能系统

中文AI进阶教材，面向有软件工程经验、愿意逐步补齐数学的读者。

**当前状态：全书完成。原90章新增2章工程实战，共92章，均通过篇幅、练习与提示检查。**

全书采用连贯正文，计算例子逐步展开，章末附练习与提示。从token、概率与反向传播起步，经过Transformer、约0.2B训练工程、Scaling Laws、推理服务，最后进入Agent、harness与前沿研究方法。

## 阅读方式

建议按目录顺序阅读：先建立直觉，再定义符号、逐项代入计算，最后联系工程实现。已有软件工程经验的读者可以通过配套微型实验核对理解，再进入训练项目与系统实战。每章末的简单练习附有提示，可用于检查是否掌握本章关键步骤。

## 篇幅口径

第1—20章保留已认可的4000—5000个正文可见非空白字符；第21章起按5000—8000检查，排除标题、Markdown标记、链接地址、代码块与LaTeX排版命令；保留正文中的数字、字母、标点与公式内容。同时单列纯汉字数量，方便核对。这些篇幅区间不是“纯汉字数量”的声称。详见篇幅记录。

## 实战与资料边界

训练项目统一使用本书设计的195072768参数模型，约0.195B，附模型实现、数据准备、训练与恢复入口。实际运行包括CPU微型Transformer、自训练BPE、SFT/LoRA、缓存数值对照，以及流式交付和harness恢复实验；195M主模型仅核对配置与参数，未开展完整训练或GPU性能测试。详见[配套代码入口](配套代码/README.md)与[篇幅及实测记录](篇幅与核验记录.md)。

基础推导由例题说明；具体模型与技术的结论需随章节核对原始论文、团队仓库或官方文档。资料索引区分已用于正文与为后续取得的资料，链接取得成功不等于所有技术细节已经核验。前沿内容不冒充涵盖截至2026年11月的全部最新发布。
